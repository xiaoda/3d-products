## 一、交付内容

1. 集中材质库 `materials.ts`：亮面白塑料、内胆、银色金属、充电触点、深色传感器、网罩衬底、几何细网、接口与指示灯；同产品按角色共享，不同产品实例隔离。
2. `lighting.ts`：五块程序化柔光箱生成 PMREM，主辅与轮廓灯、环境强度和曝光；没有下载 HDR 或产品图片参与渲染。
3. `contactShadow.ts`：以真实模型生成离屏接触阴影并模糊，状态变化时重绘；灰模不替换阴影平面，底部观察/单耳聚焦/线框时隐藏地面。
4. `cameraPresets.ts`：闭合主视觉、开盖双耳、单耳特写三组静态摄影构图，以及原八观察方向；按视口自动构图。
5. 更新材质图例、阶段说明、构图按钮和状态文字，保留开发模式灰模、线框及装配检查。
6. 保留第二阶段几何截面参数与全部几何回归测试，不将材质提升误报为几何精度提升。

## 二、用户验收步骤

1. 查看默认“开盖双耳”，确认白色外壳、暗色网罩、内胆与阴影的明暗层次。
2. 点击“闭合主视觉”，观察顶盖高光、侧面过渡、分件缝隙与落地阴影。
3. 点击“单耳特写”，放大并旋转，检查网罩、传感器、柄底触点与塑料的区别。
4. 切换背面/底部，检查铰链和 USB-C；开发模式切换“统一灰模”再取消，确认材质可恢复。
5. 缩窄窗口操作三组构图，再点“重置”；反馈是否接受当前材质、亮度、阴影与构图。重置现在恢复开盖双耳，而不是上一阶段的分开展示。
