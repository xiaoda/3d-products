# 同步展开产品展示修改计划

> 历史记录：用户随后反馈展示不美观、时间过长且中段像暂停。本方案已被 [8 秒连续版](2026-09-30-earbud-8s-continuous.md) 替代，不再代表当前节奏。

**目标：** 按用户最新反馈，以美观的整体产品展示替代分段教学：所有组件一次同步展开、不逐件放大、无数字 ID/引线/分段字幕。

**方案选择：** 不采用随机炸散（破坏秩序）或旧版依次拆解（用户已否定）；采用克制的同步悬浮展开、统一比例和固定全景尺度，仅小幅整体环绕。保留 30 秒、整体回装和播放器，先交新版预览。

**架构：** 共用一个 0–1 展开量，所有组同时起止。镜头仅对整体扫掠包络取景，不再依赖部件焦点；删除淡化、编号和章节 UI。页面改为居中的纯产品竖屏摄影棚，说明在画面外。

**技术：** 现有 TypeScript / Three.js / Vite / Vitest；复用当前本地服务，浏览器独立任务 context；不新增外部素材或依赖。

## 执行步骤

1. 修改 `src/tests/explodedFilm.test.ts`，先验证新需求：共享展开量、全部同步起止、无焦点/编号轨道；保留播放器测试。运行并确认旧版失败。
2. 简化 `src/interaction/explodedFilm.ts`；移除 `src/model/createExplodedEarbud.ts` 中的讲解淡化；根据实拍式构图调整展示位移，保留几何和原 A/B/C。
3. 重做 `src/scene/explodedFilmCamera.ts`，固定整体尺度与目标，仅缓慢环绕。修改 `src/tests/explodedMotion.test.ts`：全部时刻安全区、固定尺度、同步路径、统一不透明和碰撞采样；不隐藏失败或放宽几何阈值。
4. 精简 `src/debug/explodedEarbudReview.ts/.css`：无编号/引线/标题/讲解文字覆盖画布；保留播放暂停、进度、循环、静态视图、拖动接管、故障恢复。
5. 浏览器桌面/手机查看开场、中途及展开全景；检查真实播放与故障。全测试、类型、构建和格式验证后更新 README 与验收记录。

**边界：** 内部仍为示意，不声称精密可制造拆解。旧版验收记录保留为历史并注明被本次替代。当前不导出 MP4、不提交或推送、不使用子代理。

## 执行结果

- 步骤 1–5 完成。先验证旧版无法满足同步/无焦点约束，再实现共用展开曲线、固定全景和纯画面布局。
- 同步路径覆盖更早的壳内脱离过程；通过实际三角面检测定位声学组与电池净空不足，调整两组位置，不缩小部件或放宽相交阈值。诊断用例已移除，正式回归保留。
- 全量 26 文件 / 132 测试通过，类型、构建、格式与 diff 检查通过。浏览器桌面/手机仿真、播放至末帧、定位、循环、拖动与 WebGL 故障恢复已验证。
- 新版效果待用户确认。见 [验收记录](../acceptance/earbud-simultaneous-display.md)，不声称正式视频已导出。
