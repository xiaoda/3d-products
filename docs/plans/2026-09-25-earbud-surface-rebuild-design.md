> 状态：2026-09-25 用户已确认 B 裸壳形态、C 细节与左右耳及 D 整套装配，几何专项验收通过。用户已授权本地提交以固定基线；第四阶段动画尚未开始，需另行授权。

当前成果与边界见 [D 装配记录](../acceptance/earbud-assembly-review.md)。A / B 当时先把新裸壳放入独立开发评审页，C 确认后才在 D 接入整套；共享周期控制网格覆盖各语义区域，避免多片曲面独立拼接。下文保留原实施顺序和阶段范围，不改写历史结果。

**目标：** 修正用户指出的耳机俯视、后视及中间视角形态异常，使外轮廓、头颈过渡和表面线条同时成立，而不是只提高投影相似度。

**架构：** 保留 Three.js 程序化建模。以有明确结构含义的三维控制点和分区三次样条曲面重建单耳基础外壳，统一生成焊接网格；外壳通过视觉验收后，再挂接局部细节并更新装配包络。

**技术栈：** 现有 Three.js / TypeScript / Vite / Vitest。优先使用已安装 Three.js 的 NURBSSurface addon，不引入外部成品模型作为应用资产，不升级依赖。

### 代码证据与判断边界

1. `src/model/earbudSurface.ts` 用一串截面环描述整只耳机，中心、半径、倾角、偏航分别插值。它仍主要是带不对称扰动的椭圆截面，并非按产品结构定义的自由形状控制网格。
2. 标量保形插值不等于整个三维曲面具有平顺的曲率。当前不同环的转向、半径和中心变化缺少足够的整体约束；增加采样密度不会纠正控制曲面的形体错误。
3. `createEarbud.ts` 在曲面与附件生成后，按整个组件包围盒分别缩放三个坐标轴。本次实测缩放为 X≈1.148、Y≈0.976、Z≈0.902；这能保证外部尺寸，却也会改变曲面和孔口比例。它是必须移除的隐式形变，不把它单独认定为全部问题的原因。
4. 上轮离线拟合确实包含三维表面最近点距离、双向采样和轻量约束，并非只拟合二维剪影。但参考采样遍历可见子网格，未充分区分连续塑料外壳与开口、附件；距离较小不等于结构对应正确、曲率自然。
5. 当前自动测试覆盖尺寸、三向剪影、镜像、闭合性、法线及装配等，但不能判定产品设计线条正确。基础法线向外也不是无自交或曲面质量的完整证明。
6. 正反向正交剪影只会翻转投影方向，不能独立约束前后表面的鼓起或凹陷。因此不能仅增加一个“背面 IoU”来解决这次漏检。

判断：需要重建耳机主曲面并改变验收方法；曲面参数化、尺寸处理和参考分区应一起纠正。具体控制点不在参照坐标锁定前凭空填写。

## 二、方案选择

| 方案 | 取舍 | 结论 |
| --- | --- | --- |
| 继续调整现有截面环、提高面数或平滑法线 | 改动较小，但容易继续以局部形变弥补结构错误；外轮廓和背面可能互相牺牲 | 不作为主方案 |
| 分区控制曲面重建，先验收裸壳 | 能分别控制头部鼓面、背侧肩部、颈部和耳柄；需要处理曲面拼接及额外视觉检查 | **推荐** |
| 直接导入官方或第三方成品网格 | 不符合已确认的全部程序化建模路线，还涉及资产许可和版本来源 | 本轮不采用 |

Three.js 已提供基于控制点、节点向量和权重的 [NURBSSurface](https://threejs.org/docs/pages/NURBSSurface.html)。使用该工具只解决曲面表达和采样，不自动保证还原度或拼接连续性。

## 三、实施步骤与逐步验收

### A. 锁定参照、坐标与问题清单

**工作：**

1. 保留两个 Git 基线用于对照；不把旧版 `4e0d7aa` 视作正确模型，不执行整次提交回退。
2. 以 [Apple 中国官网](https://www.apple.com.cn/airpods-5/) 双耳、特写和产品展示为外观主依据；AR 仅用于离线辅助核对，不作为制造 CAD 或运行时资产。
3. 先核对版本、左右耳、模型层级、单位和父级姿态。用耳柄轴、出音端和背侧麦克风等可识别结构确定局部方向，不直接把 AR 展示世界轴当成产品局部轴。
4. 区分正交几何参考和官网透视照片。几何参考采用一次确定的刚体对齐与统一比例；不同观察方向不得分别拉伸模型来获得更高分数。
5. 标注头部最大宽度/厚度、背肩、头颈连接、耳柄轴、出音口方向等结构点。无法观察的区域标为近似，不补造官方尺寸。
6. 将俯视尖凸、后视肩部波动、头颈不自然过渡列为明确的必修问题；保留不参与拟合的斜视角用于独立复查。

**成果：** 同方向参考对照板、坐标约定、带结构点的形态说明、问题清单。

**验收：** 对比的是同一只耳机和可比方向，问题位置明确；不会拿斜视照片冒充正交图。确认后才确定曲面控制网格。

### B. 只重建一只耳机的基础外壳

**工作：**

1. 暂时不加入网罩、传感器、凹槽、金属触点，不改材质、灯光与充电盒。
2. 将主外壳划分为头部外鼓面、出音端所在面、背侧肩部、头颈过渡、耳柄和端部等控制区域。区域控制点有明确含义，不再把整只耳机当成不断转向的一串椭圆环。
3. 使用三次样条控制曲面采样生成 `BufferGeometry`。相邻区域共享边界数据和边界顶点索引，约束切线方向；宽阔高光区继续约束曲率变化。不是把几个封闭球体或管体重叠在一起。
4. 控制点直接在产品毫米坐标下设计，场景仅做统一单位换算；宽、高、深分别通过对应结构参数调整。移除生成完成后依赖附件包围盒的逐轴自动拉伸。
5. 先保证大体积、背肩、头颈连接及耳柄偏置，再增加局部形状自由度。若参考拟合参与优化，只拟合对应外壳区域，限制控制点移动，明确惩罚不必要的扭转与曲率振荡。
6. 对接缝、法线、退化面及非相邻面相交增加检查；单独检查收束端和颈部，不把“平滑法线”当作修复几何。

**成果：** 单耳无细节灰模；固定六向视图、至少四个斜视图；可拖动的完整旋转预览；固定条带反射或等效高光检查模式。

**验收：**

- 俯视外边线连续，不再出现当前的非设计性尖凸和波浪。
- 后视与后侧斜视的肩部、头颈过渡自然，没有当前的褶皱状起伏。
- 正面、侧面及中间角度同时成立，不以牺牲另一面换取某一张剪影接近。
- 宽阔塑料面上的检查高光连续，没有由拼接或局部曲率异常产生的突然折断。
- 尺寸、闭合性、镜像前提和数值检查通过；但这些结果不能替代用户视觉确认。

**强制停止点：裸壳未通过视觉验收，不添加细节，不调整充电盒迁就它。**
