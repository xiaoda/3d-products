# 三种背景同帧对比实施计划

**目标：** 让用户实际切换查看建筑摄影棚、冰蓝磨砂、暖白展陈三种背景，不改变耳机、排列、固定机位或 8 秒 / 1.2 秒停留节奏。

**设计：** 画布外放三个背景选择按钮，切换保留当前时间与相机，播放中也可切换。默认建筑摄影棚；URL `studio=architecture|ice|gallery` 支持直接打开对应方案。无画内编号或装饰文案。

**架构：** 独立 Three.js 背景组：弧形摄影棚几何、程序化柔光材质；冰蓝方案增加磨砂光影片；暖白方案增加低矮圆润展台。背景在 WebGL 内合成，而非只改网页 CSS，便于后续视频输出。产品灯光与模型保持一致，阴影由产品几何离屏投影并柔化。公共阴影工具以可选参数扩展，原 A/B/C 默认行为不变。

**技术：** Three.js / TypeScript / Vitest / Vite；不引入图片、外部模型或新依赖，不使用子代理、不自动提交或推送、不覆盖原 MP4。

## 实施步骤

1. 新建 `src/tests/explodedStudio.test.ts`，先测三个独立可选方案、非法输入回退、切换不影响外部节点、资源释放及阴影默认兼容；确认旧代码缺少模块导致失败。
2. 新建 `src/scene/explodedStudio.ts`；扩展 `src/scene/contactShadow.ts` 的可选地面高度/范围/透明度和高度切换接口。
3. 更新 `src/debug/explodedEarbudReview.ts/.css`，加入选择器、URL 同步和独立背景/投影生命周期；故障时禁用选择器，HMR 时释放背景资源。停留时不重复生成相同几何投影。
4. 浏览器逐版查看手机/桌面截图，验证同帧切换、播放不中断、停留不漂移、直接链接、故障恢复和控制台。
5. 全量测试、类型、构建、格式检查；文档记录三版差异及实际限制，交本地预览供用户选择。
