# 耳机中轴整齐展开实施计划

**目标：** 按用户“展开时排列整齐”的反馈调整空间关系，保持浅色摄影棚、8 秒同步开合、无停留和无标注。

**方案：** 选择两侧平行外壳 + 中轴竖排主要内部件 + 小件短横排。不选随机散射，也不选适合横屏但会压小手机主体的单行横排。

**架构：** 保留已有起始脱离曲线；由同一 `open` 驱动全部部件，主要组件以连续 `open ** 4` 权重校正到展示平面内的整齐目标。小件在此权重上再作两次连续平滑收敛，避免接近全展时仍与电路板相叠，无分组延迟或停靠阶段。目标根据实际顶点投影尺寸自动计算，内部行间距统一，不修改零件比例。微型感知与触点在展开时归并为各自横排；完整/内部静态状态恢复原位。展示基准与镜头共用，固定整体尺度不变。

**技术：** 现有 Three.js、TypeScript、Vitest、Vite；不新增依赖，不导出视频，不提交/推送、不使用子代理。

## 步骤

1. `src/tests/explodedMotion.test.ts`：先增加峰值中轴对齐、统一边缘间距、外壳平行与小件排布检查，确认旧版失败。
2. 新建 `src/model/explodedLayout.ts`：投影包围盒测量、目标布局、无历史依赖的校正。接入 `createExplodedEarbud.ts`，保留所有组同时运动和首尾复位。
3. `src/scene/explodedFilmCamera.ts` 与 `src/debug/explodedEarbudReview.ts`：共享基准方向，减少不必要的整体倾斜；默认静态展开与影片峰值一致取景。
4. 运行 `npm run test -- --run src/tests/explodedMotion.test.ts src/tests/explodedFilm.test.ts src/tests/explodedEarbud.test.ts`，保留原碰撞阈值；必要时调整共同曲线的校正权重或侧壳深度，不缩小/隐藏组件。
5. 浏览器桌面、手机实际截图检查整齐程度与留白；完整播放、首尾和控制台检查；全量测试、类型、构建、格式验证。更新 README 和验收记录。
