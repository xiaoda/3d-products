# 固定视角与展开停留实施计划

**目标：** 按用户最新要求取消持续变换视角，全部展开后短暂停留再回收；保留整齐排布、浅色摄影棚和 8 秒总长。

**设计：** 选用固定机位而非继续微环绕；0–3.4 秒同步展开，3.4–4.6 秒完整展示，4.6–8 秒同步收回。1.2 秒停留避免回到旧版长时间定格。所有组件同步，停留时布局、机位、反射均稳定。

**架构：** 只调整 `sampleExplodedFilm` 的时间映射与机位参数，不改变已经排齐的目标、空间脱离路径和模型几何。镜头位置/目标/尺度固定，手动拖动观察仍可接管并暂停影片。总时长和停留时间使用共享常量。

**技术：** 现有 TypeScript / Three.js / Vitest / Vite，无新增依赖。

## 步骤

1. `src/tests/explodedFilm.test.ts`：将旧“中段无停留”断言替换为新的 1.2 秒完整展开平台、边界连续、前后单调与全程固定 yaw/反射断言；`explodedMotion.test.ts` 加强相机位置/上方向固定及停留内全部节点矩阵一致检查。先确认旧实现失败。
2. `src/interaction/explodedFilm.ts`：用对称平滑曲线展开/回收，中间保持 open=1；移除随时间环绕和反射偏移。更新页面与入口文案，删除“无停留”。
3. 全量测试、类型、构建和格式检查；真实浏览器桌面/手机截图及完整播放，核对停留不是播放器暂停、停留后自动回收、相机始终一致。
4. 更新 README 与验收记录，旧版“无停留”要求注明已被用户最新反馈替代。

不提交/推送、不导出视频、不新增服务或子代理；复用本项目的本地服务。碰撞仍作有限采样，手机仍为浏览器仿真。

## 执行结果

四步已完成。先确认旧实现在全展平台测试失败；新版全量 26 文件 / 136 项通过，类型、构建、格式与 diff 检查通过。实际浏览器完整播放中，停留段仍是 playing，open=1，之后自动回收；全程相机参数一致。3.5 / 4.5 秒画布像素相同，桌面与手机截图已查看。见 [验收记录](../acceptance/earbud-fixed-view-hold.md)。
