# Stage 04 Motion Film Implementation Plan

> 按 executing-plans 分批实现；当前已开发与回归，待用户验收，不自动提交。

**Goal:** 在已验收模型和极简页面上实现可靠的动作闭环，以及用户确认的 20 秒、9:16 竖屏优先连续演示，为后续录屏成片交付建立统一时间线。

**Architecture:** 采用无外部动画依赖的确定性采样器和单一控制器，由现有 RAF 更新。产品动作只改变节点刚体变换；隐藏槽壁的局部避让例外详见下方实施调整；归位调用同源收纳变换。手动动作、连续演示、暂停/定位和重置共用状态，避免独立补间互相争抢。镜头轨道与模型轨道分离，方便后续帧采集复用。

**Tech Stack:** TypeScript、Three.js、原生 HTML/CSS、Vitest、Chrome DevTools MCP。

---

## 已确认的设计

- 影片约 20 秒：闭合亮相 → 开盖 → 双耳先垂直脱离收纳槽，再展开展示 → 沿原路径归位 → 关盖；首尾状态与镜头一致，支持循环。
- 连续镜头不加入无依据的“内部拆解”；只展现已建模部件。无音乐、字幕、上传、视频编码或后台录制。
- 三个主要入口：播放/暂停、操作（开合/耳机/八视角/缩放）、重置。播放时显示轻量进度和录屏设置，普通展示不堆叠参数。
- 支持 9:16 / 自适应画幅和三秒准备后的净画面播放；Esc 或点击退出净画面，空格播放/暂停。画幅不等于 1080p 导出。
- 默认不开播；减少动态效果时手动动作立即到位，连续演示仍需用户明确启动。
- 原 `?debug=1` 和耳机评审页面保留。动作中重复命令忽略，不排队；关盖会先归位；重置立即中止所有轨道。自由拖拽中断电影镜头，不与自动镜头争抢。

## Task 1：确定性动作状态与产品轨道

**Files:** Create `src/interaction/state.ts`, `src/interaction/controller.ts`, `src/model/productMotion.ts`, `src/tests/controller.test.ts`, `src/tests/productMotion.test.ts`.

1. 先写测试：20 秒采样边界、循环、任意时刻重置、快速重复命令、暂停不推进时间、定位与顺序播放相同。
2. 运行 `npm run test -- --run src/tests/controller.test.ts`，确认尚未实现时失败。
3. 实现归一化盒盖/取出进度、动作计划和固定时间采样。取出先升高，再横向展开/旋转，归位严格反向；耳机未归位禁止压盖。
4. 对实际产品采样检查归位的矩阵一致性、动作路径与槽体/盒盖关系；不放宽原几何容差。

## Task 2：场景接入与交互优先级

**Files:** Modify `src/scene/createScene.ts`; create `src/interaction/picking.ts`, `src/scene/cameraMotion.ts`, `src/tests/picking.test.ts`, `src/tests/cameraMotion.test.ts`.

1. 用现有 RAF 的时间差驱动动作与影片，隐藏标签页暂停计时、失去上下文停止、销毁释放。
2. 开盖和取出时保持安全构图；影片镜头连续移动，预设视角用轨道过渡而非直线穿过产品。
3. 点击盒盖触发动作；移动超过阈值、多指、取消事件和长按不作为点击。
4. 调试动作和正常动作进入统一取消策略；状态通过现有 `modelchange` 事件反馈，避免每帧重新构建几何。

## Task 3：最小播放界面与录屏准备

1. 保持三个主入口；将开合/取出/归位并入操作菜单，加入播放、暂停、进度、循环和 9:16 画幅。
2. 三秒准备后隐藏 UI，从 0 秒播放；Esc/点击可恢复，空格可暂停；不请求麦克风、摄像头或屏幕权限。
3. 禁用状态、键盘焦点、减少动态效果、WebGL 失败与计时器清理一起验证。

## 实施调整与验证（2026-09-26）

- 密集动作采样发现原静态内腔的局部倒扣。提出“仅修隐藏槽壁、保持外轮廓与槽口”的推荐方案后，用户要求继续任务，因此按推荐方案完成局部避让；不是重新改造耳机形体。
- 隐藏槽壁在 13–31 mm 高度区间平滑渐入/渐出，最大增加 0.55 mm 实际几何间隙；可见槽口、整个盒盖内腔哈希与修改前一致。碰撞判据和静态间隙容差未放宽。
- 初段沿收纳导向取出，完全离槽后才展开和转向。161 个时刻、左右耳所有主体顶点采样通过；这是离散采样验证，不冒充连续精确碰撞证明。
- 轻触盒盖不会触发 OrbitControls 的提前中断；只在真正拖动、多指或滚轮时交还手动控制。退出影片的缩放和空动作也同步界面。
- 桌面时间线位于竖屏画幅外侧；手机预览为操作区留空间，净画面恢复最大 9:16 画幅。
- 完成类型检查、98 项测试、构建、实际 Chrome 回归；证据、限制与人工验收项见 [第四阶段记录](../acceptance/stage-04.md)。
