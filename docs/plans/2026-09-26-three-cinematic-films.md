# 三种可选产品短片实施计划

**目标：** 按用户要求同时实现 A 光影揭幕、B 失重雕塑、C 一束光的旅行，各 20 秒；可选择播放、定位、循环、净画面录屏。

**架构：** 保留第四阶段手动动作与已验收几何。新增确定性影片采样（产品编舞/镜头/光照），共享现有时钟和 RAF。三片差异来自景别、空间轨道、灯光，不仅是换背景。UI 只增加一组三选一入口，不恢复复杂工作台。

**技术：** TypeScript、Three.js、原生 HTML/CSS、Vitest、Chrome DevTools MCP。

## 设计

- A 光影揭幕：盒盖曲线微距 → 拉开揭幕 → 双耳错峰升起 → 耳机近景与前景擦镜 → 双耳主视觉 → 归位合盖并回到微距。
- B 失重雕塑：整体悬浮、盒体微倾，双耳在完全离槽后沿不同弧线编舞，镜头绕行；不让耳机在槽内横移/旋转。结尾姿态与开头一致。
- C 一束光的旅行：深色背景，低环境光与移动主/轮廓光，依次强调盒盖边缘、耳机头部与触点，最后亮相并回到轮廓。保留暗部可读性，无频闪。
- 开始播放默认 A；“操作”菜单和播放面板都可选择片段。选择后从0秒播放，保留画幅/循环；净画面播放所选片段。重置停止并恢复标准摄影棚，保留选择。
- 所有片段共用安全取出/归位路径；额外编舞只在耳机完全离槽后启用并在归位前收回。退出影片进入手动动作时恢复统一安全轨道与标准摄影棚。
- 不改产品外形，不新增依赖、外部素材、编码/声音或自动提交。

## 实施顺序

1. 新建 `src/interaction/films.ts`、`src/tests/films.test.ts`：三片目录、采样、首尾/确定性/安全门控的失败测试，再实现。控制器增加选择，取消旧动作、清零时钟。
2. `productMotion.ts` 拆出单耳安全轨道；新建 `model/filmMotion.ts` 应用双耳编舞，根节点悬浮同源变换；测试全片采样与无累积漂移。
3. 新建 `scene/filmCamera.ts`；`lighting.ts` 暴露确定性灯光状态与恢复；`createScene.ts` 接入，不增加 RAF、几何重建或逐帧 PMREM。
4. 更新 HTML/controls/CSS：紧凑选择按钮与当前片段文案、无文字箭头；手机面板增加高度后重排安全区域；选择可键盘访问，错误时禁用，净画面隐藏。
5. 实际浏览器逐片截图检查微距/主视觉/循环；桌面和手机、切片/seek/reset/净画面回归。运行类型、全部测试、构建、格式及diff检查。
6. 更新 README 和验收记录；明确微距主动裁切、三片待用户选择，未实际生成视频；不提交或推送。

## 实施结果

三片已实现。A擦镜路径根据包围边界检测改为先前移后横移；C增加头部至柄底的微距巡礼；退出微距到手动动作时重新安全构图。110项测试通过，三片均在浏览器完整播放跨循环，桌面/手机截图及生产预览已验证。详见 [验收记录](../acceptance/stage-04-cinematic-films.md)。待用户选择，未自动提交。
