# 建筑摄影棚竖屏视频导出计划

**目标：** 将用户已选择的建筑摄影棚效果导出为手机播放的 1080×1920、30 fps、8 秒 MP4。

**方案：** 复用已验证的本地逐帧 PNG → FFmpeg 管线；调用现有开发评审场景与确定性时间定位，不修改模型、镜头、编排或灯光。导出辅助服务仅监听 127.0.0.1，使用随机令牌限制写入，无窗口启动，日志及 PID 留在 `.local/earbud-architecture-export/`。

**步骤：**
1. 检查现有开发服务归属和编码器；新建独立浏览器上下文，画布设为原生 1080×1920、DPR 1，确认建筑摄影棚和固定构图。
2. 逐帧采样 240 帧；时间为 i/30，最后一帧取 8 秒确保完整收合。保留原 3.4–4.6 秒展开停留。
3. 编码 H.264 High / Level 4.1、yuv420p、CRF 18、faststart，无音轨。输出 `exports/耳机展开-建筑摄影棚-1080x1920-30fps.mp4`，禁止覆盖已有视频。
4. ffprobe 检查尺寸、帧率、时长与帧数；完整解码检测错误；抽取开头、展开中、全展、收回中与结尾查看。浏览器加载成片并实际播放验证。
5. 更新导出验收记录，关闭本次导出页和辅助服务，保留既有项目预览服务；交付本地视频链接，不自动提交或上传。
