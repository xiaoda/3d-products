# AirPods 5 · 交互式三维展示

纯 Three.js 程序化产品建模项目，当前版本 **0.4.0**。第三阶段后的几何校准 `636d080` 未通过用户形态验收，后续 B / C / D 曲面与装配基线已通过验收。

**当前检查点：第四阶段已实现，用户已确认三种短片效果基本满意并授权提交、推送。** 已验收的模型、收纳姿态与极简页面保持为基线；本阶段增加动作闭环与三种可选的 20 秒产品短片，竖屏优先。见 [第四阶段验收记录](docs/acceptance/stage-04.md) 和 [实施计划](docs/plans/2026-09-25-stage-04-motion-film.md)。按用户明确要求交付版本，提交标识见 Git 历史。

首页三个主要入口是 **播放演示 / 操作 / 重置**。“操作”中包含开合、双耳取出/归位、八个视角与缩放；动作平滑衔接，重复动作忽略，关盖前自动归位，拖拽接管自由观察。“重置”恢复默认开盖收纳；影片从闭合开始。

## 单耳同步展开（8 秒定机位版，开发预览）

开发服务添加 **`?review=earbud-exploded`**，或从 `?debug=1` 的链接进入。本次实际地址为 `http://127.0.0.1:61550/?review=earbud-exploded`，重启后以实际端口为准。按最新反馈改为 **8 秒定机位展示、所有部件一次同步展开、全展后停留 1.2 秒再回收、无数字编号/引线/逐件特写**。浅色摄影棚下，**两片外壳平行分列两侧，主要内部件沿竖向中轴排列，小零件合成短横排，展开终点统一行间距**。影片中相机位置、方向、目标与尺度保持不变，不再持续环绕；保留完整/内部/展开静态视图和播放、暂停、重播、进度、循环。拖动暂停并自由观察，继续播放平滑回到固定导演机位；首次不自动播放。

这是独立结构示意模型：保留已验收的外表面，新增示意切壳、内壁及主要功能组件。新版调整展示间距与两处内部净空位置，不缩放单个部件。**内部尺寸、布局、壳体分件和连接方式不是实物精密复原，也不是维修指南。** 不更改现有 A/B/C 影片；评审模块不进入生产构建。

用户最新要求已替代上一版“持续环绕、无中段停留”：**0–3.4 秒同步展开 → 3.4–4.6 秒保持完整展开 → 4.6–8 秒同步回装**。停留是影片内的展示段，不是暂停播放器，到时自动回收。**建筑摄影棚版已按用户选择导出 1080×1920 / 30 fps MP4**，不覆盖已有失重雕塑影片。见[固定视角修改计划](docs/plans/2026-09-30-earbud-fixed-view-hold.md)、[动作验收记录](docs/acceptance/earbud-fixed-view-hold.md)和[视频导出验收](docs/acceptance/earbud-architecture-export.md)。

最新的“排列更整齐”调整见[中轴布局计划](docs/plans/2026-09-30-earbud-aligned-layout.md)和[中轴布局验收记录](docs/acceptance/earbud-aligned-layout.md)。取景与布局按实际顶点投影测量，不把曲面包围盒的空角当作产品尺寸；不通过缩小单个部件消除重叠。

### 三种背景对比（新增本地预览）

评审页上方可切换 **建筑摄影棚 / 冰蓝磨砂 / 暖白展陈**，切换保留当前时间、播放状态和相机，方便同一帧比较；重播沿用所选背景。也可在原评审 URL 后添加 `&studio=architecture`、`&studio=ice` 或 `&studio=gallery`，未指定时默认建筑摄影棚。

三版分别采用浅灰弧形空间与斜向柔光、冰蓝空间与磨砂光影、暖白空间与圆润低展台。产品灯光、几何、整齐布局、8 秒片长与 1.2 秒停留不变。背景及柔化投影已合成进 WebGL 画布，不再只依赖 CSS 底色；磨砂和布景光影是视觉近似，不是光学仿真。三版预览之后，用户选定建筑摄影棚并要求导出，随后授权提交相关代码及推送 GitHub。见[三背景验收记录](docs/acceptance/earbud-three-studios.md)。

### 建筑摄影棚成片

本地文件（不随 Git 提交）：`exports/耳机展开-建筑摄影棚-1080x1920-30fps.mp4`。原生 9:16 竖屏、1080×1920、30 fps、8 秒 / 240 帧、H.264 High / Level 4.1、yuv420p、faststart，约 0.94 MB，无音轨。画面不含网页按钮或标注。通过逐帧渲染编码、完整解码和浏览器播放验证；不是手机实机兼容性全量测试。页面尚未提供一键下载功能。

### 失重雕塑建筑摄影棚版（导出准备）

`createScene` 支持可选布景工厂，默认主页 A/B/C 的背景与动作不变。为失重雕塑准备了建筑摄影棚接入，布景不参与产品取景、反射环境生成或接触阴影投射。代码通过 28 个文件 / 142 项测试，**但新版 20 秒 MP4 尚未生成，环绕机位下的布景也尚未完成视觉验收**：本地导出服务启动命令在执行前被工具拒绝，具体触发原因未查明。见[导出准备记录](docs/acceptance/sculpture-architecture-export.md)。`.local/` 中的任务专用导出脚本与日志不随此次 Git 提交，原失重雕塑视频不变。

## 连续动画与录屏

1. 启动开发服务，打开实际输出的地址；本次为 `http://127.0.0.1:61550/`，重启后端口可能变化。
2. 点击“播放演示”默认播放 A；也可在“操作”菜单或播放面板选择 **A 光影揭幕 / B 失重雕塑 / C 一束光的旅行**，选择后从头播放。每段 20 秒，默认循环；取消循环后停在末帧。
3. 点击暂停或拖动进度条定位；可切换 **9:16 竖屏 / 自适应画幅**。
4. 使用系统或自己的录屏软件，选择中央竖屏区域；点击“净画面录屏”，准备 3 秒后界面隐藏并从头播放。**Esc 或点击画面退出，空格暂停/继续**。准备期间按 Esc 也可取消。
5. 录屏后裁掉准备部分及外侧留白。现在没有自动视频文件下载；9:16 指画布比例，不代表已经导出 1080×1920 视频，也不保证真实设备的录制帧率。

### 三种短片

| 片段           | 主要差异                                                         |
| -------------- | ---------------------------------------------------------------- |
| A 光影揭幕     | 盒盖微距揭幕、双耳错峰升起、耳机头部近景、前景擦镜、主视觉收束   |
| B 失重雕塑     | 整体悬浮、盒体微倾、双耳错层弧线、相机空间环绕，冷色浅背景       |
| C 一束光的旅行 | 深色背景与移动柔光、轮廓揭幕、头部到柄底触点的细节巡礼、整体亮相 |

微距段有意裁切产品，不是构图失误。三片仅改变动作、镜头与灯光，不改产品曲面；切回手动操作会恢复标准摄影棚、安全姿态及完整构图。重置保留片段选择。详见 [三片验收记录](docs/acceptance/stage-04-cinematic-films.md)。

本阶段不含 MP4 编码、音乐、字幕或上传平台。第五阶段完善成片构图和图片输出；第六阶段验证真实设备连续录制与性能。

仅在开发模式添加 **`?debug=1`** 显示几何检查面板：闭合 / 开盖 / 分开展示、单耳六向与四斜视、灰模、条带高光、盒盖与收纳正交检查。普通开发预览与生产页面都不自动显示该面板。

几何复查时可选择 **“收纳正交正视 / 收纳正交顶视”**，勾选“隐藏耳机”检查孔位。收纳位置由 `earbudPlacement.ts` 统一用于正式耳机与腔体包络；单耳检查清除收纳旋转，回到整套时恢复。

添加 **`?review=earbud-details`** 或从 `?debug=1` 检查面板进入局部对照：左侧裸壳、右侧恢复细节，支持七项开关、左右耳及四种材质。它不改变主页面装配。详见 [C 验收记录与对照图](docs/acceptance/earbud-details-review.md)。

原 **`?review=earbud-shell`** 保留 B 与修正前模型的同机位比较，见 [裸壳记录](docs/acceptance/earbud-shell-review.md)。两个评审入口均不进入生产构建。

## 第三阶段验收

1. 打开预览，使用“操作 → 合上盒盖 / 打开盒盖”和“操作 → 单耳特写”检查三种构图。
2. 旋转模型，检查白色塑料的高光、银色触点/铰链、深色网罩与传感器的反射差异。
3. 查看底部接触阴影和内胆；底部观察与单耳聚焦时会隐藏地面阴影，避免遮挡。
4. 在 `?debug=1` 勾选“统一灰模”对照几何，再取消；点击“重置”恢复开盖双耳与物理材质。
5. 缩窄窗口操作，参考 [第三阶段验收记录](docs/acceptance/stage-03.md) 反馈材质、光照与构图。

历史第三阶段只增加材质和摄影棚表现；本次专项另行修改了耳机曲面、盒盖胶囊截面、收肩和非圆收纳槽。几何仍是图片近似，不是工程 CAD；材质参数也不是实物测量值。接触阴影为几何投影与模糊近似，不是光线追踪。正式开合/取出动画与连续影片已在第四阶段实现；热点与 PNG 导出仍属于后续阶段。为排除取出时局部倒扣，隐藏槽壁增加最大 0.55 mm 的局部避让；外轮廓、槽口与盒盖不变，槽口和盒盖内腔哈希回归通过。

一般视角保留当前装配；“内胆”切换为空盒开盖，“单耳特写”只显示右耳。“重置”恢复开盖双耳并清除检查选项。尺寸指各部件在**未施加展示姿态时的局部包围尺寸**，不是组合展示场景的包围尺寸；指示灯与铰链保留微小表面偏移，闭合盒总尺寸偏差低于 1%。

## 材质与灯光参数

- `materials.ts`：外壳粗糙度 0.24、清漆权重 0.85；银色金属 metalness 1；网罩哑光衬底 roughness 0.82。均为艺术调校，不代表实物材质检测结果。
- `lighting.ts`：五块柔光箱生成 256 级 PMREM，ACES 曝光 1.05，环境强度 0.8；模型自阴影使用 1024 PCF 阴影图。
- `contactShadow.ts`：512×512 接触阴影，随场景状态改变更新；日常相机渲染不逐帧重建环境贴图。
- `cameraPresets.ts`：相机方向、构图距离倍率与静态姿态映射。手动构图按主体包围球适配；影片用 `cameraMotion.ts` 按包围盒投影保留横纵安全边距。
- 当前不需要外部纹理文件，因此未创建空的 `public/textures/`。详见 [运行时素材清单](docs/asset-manifest.md)。
